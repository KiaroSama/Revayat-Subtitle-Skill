## Compatibility and recovery

The project/build JSON schema remains version 2. The generation recipe and
normalization recipe advance to 3 because SRT normalization can change emitted
bytes. The sampler advances to 3 because repeated animations need additional
frames. Workspaces keep their original sources, translations, IDs and glossary.
Run `build --work WORK`, then render and inspect the new edition; old build
directories are preserved and old image approval is not transferred.

Keep `font_policy`, every-line editorial review, parallel-work consent, source
hashing, canonical episode IDs, donor provenance and explicit timing conversion.
No renderer/provider dependency, runtime package, or automatic GPU path is added.

The ordinary path policy rejects pre-existing symlinks/junctions inside a workspace.
It is not an operating-system sandbox or a guarantee against an adversarial process
racing every filesystem operation. User-selected external video, font and previous
glossary inputs remain explicit inputs rather than workspace artifacts.

## Reference implementations and specifications

- [CPython zipfile](https://github.com/python/cpython/blob/main/Lib/zipfile/__init__.py)
  and [ZIP documentation](https://docs.python.org/3/library/zipfile.html):
  distinguish archive-directory validity from backend decompression failures.
- [pathlib resolution](https://docs.python.org/3/library/pathlib.html#pathlib.Path.resolve):
  resolving a linked output root changes its physical destination; validate the
  workspace boundary before creating output rather than afterwards.
- [Aegisub ASS override tags](https://aegisub.org/docs/latest/ass_tags/) and
  [Aegisub](https://github.com/TypesettingTools/Aegisub): event-local animation and
  formatting are not represented solely by a reused style signature.
- [libass regression tests](https://github.com/libass/libass-tests):
  separate actual rendered fixtures from structural/metadata checks.
- [PNG specification, palette](https://www.w3.org/TR/png-3/#11PLTE) and
  [specification repository](https://github.com/w3c/png): one optional palette
  for the supported truecolor profile, before image data.
- [Hypothesis](https://github.com/HypothesisWorks/hypothesis):
  keep generated tests focused on invariants and retain concrete regressions.
- [Existing upstream research](../skills/revayat-subtitle/references/research.md):
  retain the larger comparative survey and its licensing/adaptation boundaries.
