# روایت زیرنویس — Revayat Subtitle

[English](README.md)

اسکیل و پلاگین ترجمهٔ زیرنویس انگلیسی به فارسی گفتاری، یا اصلاح کامل زیرنویس
فارسی؛ مشابه [روایت کمیک](https://github.com/KiaroSama/Revayat-Comic-Skill) و
[روایت رمان](https://github.com/KiaroSama/Revayat-Novel-Skill).
خود عامل ترجمه و بازبینی می‌کند؛ اسکریپت‌ها ساختار فایل، بررسی پوشش خطوط، رندر
و بسته‌بندی را انجام می‌دهند.

- بررسی تمام خطوط تمام نسخه‌ها، تحقیق دربارهٔ انیمه و واژه‌نامهٔ مشترک بین فصل‌ها.
- فارسی روان و گفتاری، حفظ پسوندهای ژاپنی و تمام محتوای داستان، بدون سانسور.
- اولویت قالب ASS، انتخاب یا ادغام محتوای بهتر، مرتب‌سازی زمان و اصلاح RTL و نقل‌قول‌ها.
- حذف تبلیغات تأییدشده، خطوط خالی، کامنت‌های مخفی و استایل‌های استفاده‌نشده.
- حفظ افکت‌ها و فونت‌های جاسازی‌شده؛ **حذف فونت اختیاری است و پیش‌فرض خاموش است**.

خروجی هر قسمت یک فایل مانند `S01E01.ass` یا `S01OVA01.ass` است؛ همه در پوشهٔ
`Sub` داخل ZIP قرار می‌گیرند. ورودی‌های صرفاً SRT همان قالب را نگه می‌دارند.

## نصب

Python 3.10 یا جدیدتر، FFmpeg دارای libass و یک فونت فارسی لازم است. عامل باید
دسترسی به فایل، اجرای دستور، جست‌وجوی وب و مشاهدهٔ تصویر داشته باشد.

ویندوز، در PowerShell:

```powershell
./install/install.ps1 --agent codex
./install/install.ps1 --agent claude --scope project --path 'C:\Projects\Anime'
```

Linux و macOS:

```bash
bash install/install.sh --agent codex
```

عامل‌های پشتیبانی‌شده: Claude Code، Codex، Cursor، Kiro، Cline، Hermes، OpenCode،
Antigravity IDE و Antigravity CLI. گزینهٔ `--agent all` عامل‌های موجود را شناسایی
می‌کند؛ `--dry-run` مقصدها را نشان می‌دهد و `--force` قبل از جایگزینی نسخهٔ موجود
از آن نسخهٔ پشتیبان نگه می‌دارد. نصب‌کننده پیش‌نیازها را خودکار نصب نمی‌کند.
مسیر دقیق نصب را می‌توان با `--destination` تعیین کرد.

## پلاگین

بسته دارای مانیفست استاندارد Agent Plugins و مانیفست‌های سازگار با Claude،
Codex و Cursor است. نصب Claude:

```text
claude plugin marketplace add KiaroSama/Revayat-Subtitle-Skill
claude plugin install revayat-subtitle@revayat-subtitle-marketplace
```

برای ساخت یک کپی پلاگین در مقصد دلخواه:

```text
python install/install.py --plugin --destination "PATH/revayat-subtitle"
```

فعال‌سازی را در مدیر پلاگین خود عامل انجام دهید. Kiro Powers، Hermes و
Antigravity نیز از قالب استاندارد پشتیبانی می‌کنند. برای Cline و OpenCode از
نصب اسکیل استفاده کنید؛ سیستم افزونهٔ JS/TS آن‌ها قالب متفاوتی دارد.
[مسیرها و مستندات هر عامل](docs/platforms.md) در پروژه ثبت شده‌اند.

## استفاده

نام انیمه، فصل و جدیدبودن یا ادامهٔ مجموعه را بگویید و فایل‌های ASS/SRT یا ZIP
را ضمیمه کنید. برای ادامهٔ مجموعه، واژه‌نامهٔ قبلی را هم بدهید:

> از revayat-subtitle استفاده کن. این فصل دوم همان انیمه است. همهٔ خطوط و
> نسخه‌ها را بررسی کن، نام‌های قبلی و پسوندهای ژاپنی را نگه دار، فارسی گفتاری
> بنویس، فونت‌ها را حفظ کن و Sub.zip و واژه‌نامهٔ به‌روزشده را بده.

در Codex می‌توان `$revayat-subtitle` را فراخوانی کرد. پس از نصب، عامل را reload
کنید. مراحل و قرارداد فایل‌ها در [اسکیل](skills/revayat-subtitle/SKILL.md) و
[راهنمای اجرا](skills/revayat-subtitle/references/workflow.md) آمده‌اند.

```text
python skills/revayat-subtitle/scripts/revayat-subtitle.py doctor
```

اگر FFmpeg در PATH نیست، `REVAYAT_FFMPEG` یا `--ffmpeg` مسیر آن را مشخص می‌کند.
وابستگی Python اضافی، سرویس پس‌زمینه یا API ترجمهٔ پولی وجود ندارد.

## بررسی و محدودیت‌ها

تمام خطوط باید تصمیم ثبت‌شده داشته باشند. ساخت و بسته‌بندی، شناسه‌ها، هش
فایل‌های ورودی و خروجی، نگاشت قسمت‌ها و تصاویر رندرشده را بررسی می‌کنند.
مشاهدهٔ تصویر و درستی معنایی ترجمه همچنان مسئولیت عامل است؛ تیک بررسی به‌تنهایی
این موارد را اثبات نمی‌کند.

بدون ویدئوی اصلی، رندر روی زمینهٔ خنثی است و هماهنگی صدا و تصویر را اثبات
نمی‌کند. فرمت‌های دیگر، نسخه‌های ویدئویی ناسازگار، ASSهای دارای بوم متفاوت،
فونت‌های متعارض و مارک‌آپ پیچیده به تطبیق صریح نیاز دارند. در زمان ساخت اسکیل،
فایل واقعی انیمه ضمیمه نشده بود؛ نمونه‌های مخزن مکانیک پردازش و نمایش را
می‌سنجند، نه کیفیت ترجمهٔ یک فصل واقعی.

دستور بررسی محدودشده `python tests/check.py` است؛ برای FFmpeg گزینهٔ `--render`
را اضافه کنید. CI برای Windows، Linux و macOS تعریف شده و رندر libass را روی
Linux اجرا می‌کند. سازگاری قالب بسته با آزمون داخل تک‌تک برنامه‌ها متفاوت است.

هر اجرا یک لاگ جدید UTF-8 با زمان UTC در `logs/` داخل اسکیل می‌سازد؛ مسیر با
`REVAYAT_LOG_DIR` قابل تغییر است. متن زیرنویس در لاگ ثبت نمی‌شود. در نصب فقط‌خواندنی،
گزارش خطا به stderr می‌رود. لاگ‌ها تا زمان حذف توسط کاربر حفظ می‌شوند.
