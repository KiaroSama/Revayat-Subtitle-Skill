## Compiled compatibility contract

The compiled extension exports `REVAYAT_NATIVE_CONTRACT = 1`; the Python facade
reads that value from the binary. A missing or different epoch causes an
actionable `ImportError`, so a newly updated wrapper cannot silently call an old
normalizer with different protected-text behavior. Rebuild or reinstall the
extension and its Python package together from the same checkout. The epoch
describes API and behavior compatibility, not authenticity or a security
boundary. The bundled `persian_lint.py` remains an independent Python script.

When an accelerated API or its observable behavior changes incompatibly, advance
the compiled epochs, facade/dispatcher checks and parity expectations together.
Changing only a wrapper's advertised version does not establish compatibility.
