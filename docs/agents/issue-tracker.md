# Issue tracker

Report reproducible defects through the project's
[GitHub issues](https://github.com/KiaroSama/Revayat-Subtitle-Skill/issues).
Include the helper version, platform, command, controlled diagnostic and a small
authored reproduction. Do not upload private subtitles, videos, fonts or activity logs.
The shipped skill defines subtitle decisions and review contracts; a development
issue or passing CI does not approve a translation.
