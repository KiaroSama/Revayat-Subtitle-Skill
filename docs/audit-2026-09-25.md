## Findings, implementation and acceptance

### N1 — SRT HTML breaks become literal text in ASS donors

`pieces` did not recognize `<br>`, so `visible`, line cleanup and bidi normalization disagreed with FFmpeg. `srt_to_ass` emitted `A<br>B` literally rather than `A\NB`. The shared `SRT_BREAK` tokenizer now models supported case/spacing/slash variants as a logical newline. Donor conversion uses the same recognizer. Literal `< 5 >`, entities and ordinary formatting are preserved; unsupported rich markup still requires explicit adaptation. Tests verify visible text, per-line marks, empty break lines, donor bytes and actual FFmpeg pixel equivalence to a newline.

### N2 — ASS argument semantics and missing tags disagree with libass

`{\r(Default)}` was treated as a reference to a style named `(Default)`, while libass uses `Default`; parenthesized font/drawing arguments had the same boundary error. `\fr` was not recognized and `\be` was misread as `\b` with argument `e1`. The scanner now separates scalar argument syntax from its value/spans, preserves complex arguments and nested transforms, and recognizes `fr`, `be` and `fsc` before shorter prefixes. Scalar consumers use the first nonempty argument, retaining ignored source arguments. Drawing-mode detection avoids unbounded integer conversion. Tests cover reset remapping, font names, drawing/text transitions, aliases, nested transforms and rendered scalar equivalence. This does NOT claim that a literal style name beginning with parentheses is the same as parenthesized argument syntax.

### N3 — Normalization breaks valid bidi scopes crossing display lines

A balanced source such as `RLI + سلام OVA + \N + دنیا + PDI` passed input validation but failed after a generated per-line PDF was inserted inside the source isolate. Lines whose source scopes cross a display boundary now receive direction marks without an additional embedding wrapper. Self-contained lines retain normal mixed-script embedding. Original controls, logical prose and tags stay intact. Tests cover LRI/RLI/FSI, LRE/RLE, both ASS breaks, SRT newlines, nested scopes, invalid controls and 250 seeded cases. This is scope-preserving normalization, not a replacement UAX #9 renderer.

### N4 — Binary transforms pass encoding preflight and then raise LookupError

`codecs.lookup` accepts `base64`, `rot13`, `hex`, `bz2` and `zlib`, which are not supported text decoders for `bytes.decode`. Import and persisted project validation now share a text-codec check with a nonempty sentinel; incomplete Unicode sentinel decoding is distinguished from a non-text transform. Tests exercise real CLI exit 2 without traceback/publication and preserve UTF-8, UTF-16, UTF-16-LE and CP1256 imports. Diagnostics do not echo arbitrary supplied values.

### N5 — Artifact readers can block on special files

A FIFO named `record.json` has a small stat size but opening it waits indefinitely for a writer. Bounded byte reads now require a regular file and a valid integer limit before opening, and recheck the opened descriptor. Existing-build subtitle comparison also uses the bounded reader. A native POSIX child-process test proves FIFO refusal without waiting; ordinary size/error checks remain cross-platform. This rejects pre-existing special artifacts, not every adversarial filesystem race or operating-system sandbox escape.

### N6 — JSON producers can publish records their readers refuse

A 12,582,947-byte accepted authored SRT containing escape-expanding control characters produced a 75,497,716-byte worksheet: `prepare` succeeded and `load` immediately failed its 64 MiB JSON limit. The writer and reader now share `MAX_JSON_BYTES`; oversized serialization fails before publishing a file/workspace. The writer checks short writes, preserves existing targets and does not mask a primary failure with cleanup errors. CI uses scaled limits for cheap deterministic expansion tests; the full-size case was also reproduced locally.

### N7 — Legacy Effect animations and event layouts lack sampling coverage

Three same-style events with `Banner;1;0;0` or either Scroll effect yielded only first/last midpoints. Animation recognition now includes event-local Effect fields, and every such event receives phases. Event layout fields participate in static signature selection. Tests verify repeated Banner/Scroll events, margins/layers, newly recognized rotation/blur tags, static deduplication and frame budgets. Existing override-animation tests remain intact. Sampler recipe advances to 4.

### N8 — Duplicate ASS-section checks are quadratic

Each incoming section rescanned all preceding section names. At 1,000/3,000/6,000 small authored custom sections, measured baseline times were about 0.042/0.387/1.528 seconds. A case-folded membership set removes the quadratic scan while retaining section order and duplicate refusal. The 6,000-section case measured about 0.016 seconds after the change in the same Linux session; timings are observations, not portable thresholds. CI asserts fidelity and duplicate handling, not a fragile wall-clock ratio.
