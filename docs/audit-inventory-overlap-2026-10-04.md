## I01 — Import reads its own staged output as another input

**Priority: medium. Affected paths:** `workflow.prepare`, `inputs`, `input_candidates`.

The importer creates an owned temporary workspace before walking all user roots. The input generator enumerates each root lazily. With an explicit subtitle followed by a directory containing both that subtitle and the working-directory parent, the second traversal sees the first source's newly staged copy. The generated copy gets another source ID and review worksheet. Repeated overlapping roots can progressively multiply these copies, consume import limits, and require review of candidates the user never supplied.

A minimal public API reproduction is:

```python
prepare([root / "input.srt", root], root / "work", "Authored audit",
        1, "utf-8", None, "en")
```

Before repair, this imports **3** candidates: the original from the first root, a `.subtitle-import-.../work/sources/s0001.srt` generated file, and the original from the second root. Expected: **2** user-root contributions with their distinct root provenance. This is not a request to silently deduplicate explicitly repeated caller roots. A repeated directory-only input likewise grows the inventory from its own artifacts.

**Implemented correction:** propagate an optional, internal `excluded_root` from the actual `staging_directory` yielded path through `inputs` into `input_candidates`. Map the resolved owned staging tree into each root's original lexical spelling once, so relative roots, parent (`..`) segments and ancestor aliases cannot expose it. Skip that exact directory before descending or charging the external traversal budget. Use component-aware containment and exact path equality, not a string prefix, glob, or a blanket exclusion of hidden/staging-looking directories. Preserve original root labels and member paths. Existing input link/reparse checks run before enumeration and are not replaced by path resolution.

The excluded subtree is owned by this operation. Unrelated folders named `.subtitle-import-authored` remain real inputs, as do path-prefix neighbors. User source bytes, repeated-root provenance, ZIP member origin/index, root order, import-size limits and transactional refusal remain unchanged. No global exclusion state leaks into subsequent imports.

**Acceptance:** explicit file then parent, repeated directory roots, ZIP then parent, nested overlapping roots with duplicate basenames, relative paths and parent segments, exact subtree versus prefix neighbor, staging-looking genuine input, external traversal limits, late invalid-source failure and corrected retry, public CLI and subsequent workspace load. Inventory output must contain no candidate generated by its own import.

## O01 — Chronological ASS sorting changes the displayed composition

**Priority: high. Affected paths:** `subtitle_formats.serialize`, `workflow.assemble`, `render.sample_plan`.

ASS physical event read order participates in same-layer compositing. The former implementation independently sorted cues by start time in `assemble` and again in `serialize`. Sorting ties stably does not protect overlapping events with **different** start times. Reversing their row order can change which event is on top without any worksheet edit or structural note.

A minimal authored example has a red vector first, active from `2.00` to `4.00` seconds, followed by a blue vector at the same position/layer, active from `1.00` to `3.00`. At `2.50`, the source is blue on top. The old chronological rewrite makes red the top vector. Local FFmpeg 7.1.5 produced different full-raster SHA-256 values:

| Raster | SHA-256 |
|---|---|
| Original, blue on top | `3e73f3195f9ce84c09f9df6387790e9e366c0159eee61f0e7ba558aa00bf4270` |
| Old chronological rewrite, red on top | `34ec42d3e7051e4599759159298c870c31735683a7acd5a33bd4d372802c250f` |
| Corrected rewrite | Identical to the original raster in this environment |

These are environment-specific authored controls, not portable golden hashes or three separate bugs. Tests compare original/corrected pixels produced by the same equipped runner and include an intentionally wrong-order negative control. Vector fixtures do not redistribute fonts or media.

### Implemented algorithm

`presentation_order(cues, kind)` returns original indices rather than detaching cues from provenance:

1. Validate and compute effective emitted timestamps, including ASS floor-to-centisecond conversion.
2. Sort indices by emitted start time.
3. For ASS, sweep the sorted half-open intervals into **connected overlap components**. A new component begins only when its start is at or after the current component's maximum end.
4. Emit components chronologically, but emit each component's indices in their original incoming order.
5. For SRT, retain ordinary stable chronological ordering and block renumbering.

The sweep is `O(n log n)` time, `O(n)` space. It handles transitive overlap bridges, nested/long-lived events, stable equal starts and exact end/start touching without pairwise quadratic scanning. Any two simultaneously active ASS events lie in the same component, so their original relative read order is preserved. Absolute layer/style/effect/vector fields are untouched. Disjoint components cannot be active together and may safely be moved relative to one another.

This does **not** blanket-refuse valid overlaps, flatten layers, invent replacement layers or concatenate vector payloads. Within a shared overlap group, retained base events precede retained donor events in the declared source order; each source retains its own incoming event order. That deterministic cross-source policy is explicit, not inferred from arbitrary start-time ties.

`assemble` uses the returned indices on complete `(cue, provenance)` pairs before assigning `emitted_index`. `serialize` applies the same idempotent ordering, preventing a second independent reorder from invalidating provenance. Edited timings use emitted rather than original bounds. Repeated builds remain deterministic.

An ASS overlap component can intentionally contain nonchronological rows. `sample_plan` therefore adds the true minimum-start and maximum-start cue indices explicitly, while preserving prior physical boundary, changed-structure, style, drawing, animation and mixed-text coverage. Sample times remain sorted; indices always address actual emitted rows. The empty-document helper reports a controlled error. This is representative visual sampling, not certification of every possible overlap phase or complete audio synchronization.

**Acceptance:** native before/after and wrong-order controls; multiple phases/components/layers; disjoint sorting; transitive bridges; half-open touching; quantized boundaries; invalid collapsed timing; no input mutation; SRT behavior unchanged; 250 deterministic generated interval sets checking all overlapping pairs and idempotence; a bounded 100000-event connected component; worksheet retiming; retained donors; exact emitted provenance; chronological sample edges; existing-edition preservation; full build → render → unreviewed-QA refusal → explicitly labelled mechanical review fixture → hash-checked ZIP; stale sampler refusal.
